# Електрика — інтерактивний практикум

Сайт на TypeScript, Vite та Three.js WebGPURenderer. Вісім окремих сторінок лабораторних мають намальовані лабораторні установки з інтерактивними приладами, журнал вимірювань, розрахунки, теорію та контрольні питання. Взято підхід до рендерингу із сусіднього проєкту `wawes`; його код і файли не змінювалися.

Сайт залишено локальним за запитом користувача; онлайн-публікацію не виконано.

## Запуск

Потрібен Node.js, сумісний із Vite 8 (22.12+ або 24+).

```sh
npm ci
npm run dev
```

Локальна адреса: `http://127.0.0.1:5174/`. Для production:

```sh
npm run build
npm run preview
```

Збірка лежить у `dist/` і придатна для статичного хостингу. Маршрути використовують hash: `#/lab/1` … `#/lab/8`, тому серверні правила маршрутизації не потрібні.

## Можливості

| Робота | Інтерактивність |
| --- | --- |
| 1. Міст Уітстона | Перетягування контакту реохорда, ручка магазину опору, гальванометр, заміна зразка |
| 2. Компенсація ЕРС | Два елементи, перемикання еталона, контакт реохорда й нульовий індикатор |
| 3. Температура й опір | Водяна ванна, нагрівач, термометр, перемикання щупів та поступове нагрівання зразків |
| 4. Діод | Намальований діод зі зміною полярності, регулятор напруги, амперметр і вольтметр |
| 5. Осцилограф | Осцилограф з екраном, ручками, режимом XY та звуковим генератором |
| 6. Закон Ома для AC | ЛАТР, реостат, вилучення конденсатора, вставляння осердя, покази A і V |
| 7. Коефіцієнт потужності | Реальний перемикач лампи/котушки, світіння ламп, ватметр, A і V |
| 8. Міст Сотті | Два конденсатори, контакт реохорда, джерело AC та нульовий вольтметр |

Власні вимірювання вводяться в редаговану таблицю. «Демо серія» додає окремо позначені покази моделі, зберігаючи попередні рядки. Редагування демонстраційного показу переводить його в категорію власних даних. Увімкни живлення на установці; у нульових методах запис доступний після балансування. Ручки й контакт можна перетягувати або регулювати стрілками клавіатури. Натискання на гніздо вимірювального приладу від’єднує або відновлює провід. На вузькому екрані стенд можна прокручувати горизонтально. Під кожним стендом наведено підказки, а біля розрахунків похибки — прийняті припущення.

Дані зберігаються в `localStorage` окремо для кожної роботи. Вони не надсилаються на сервер. Є CSV-експорт із UTF-8 BOM, одиницями, джерелом даних та повідомленнями про помилки. Після очищення таблиці її можна відновити кнопкою в повідомленні. Максимум — 200 вимірів на роботу.

## Рендеринг

Прилади, дроти, шкали, пробірки, реохорд і перемикачі намальовано у SVG. Прозорий WebGPU-шар додає умовну анімацію руху заряду та промінь всередині екрана осцилографа. Кожен стенд має окреме компонування й діючі елементи керування; самостійних графіків на основному екрані немає.

TSL компілюється в WGSL для WebGPU. На GPU обчислюються положення частинок у проводах та вершини променя осцилографа. Числові покази, прогрівання й регресія обчислюються у TypeScript. Рух крапок показує роботу кола умовно; прогрівання термостата прискорено для навчальної демонстрації.

Якщо WebGPU недоступний, Three.js використовує WebGL 2. Якщо GPU-рендерер не ініціалізується, працює Canvas 2D з тією самою моделлю. Для перевірки резервного режиму додати `?renderer=canvas` перед hash: `/?renderer=canvas#/lab/5`. Фактичний backend доступний в атрибуті `data-backend` елемента `#bench`.

Приховані сторінки не анімуються. Налаштування `prefers-reduced-motion` зупиняє анімацію на старті; промінь і частинки залишаються видимими. Інтерфейс підтримує вузькі екрани та керування вкладками клавіатурою.

WebGPU завантажується окремим модулем після інтерфейсу. Його доступність визначається браузером і середовищем запуску; локальна розробка працює на localhost, хостинг — на HTTPS.

## Перевірки

```sh
npm test
npm run build
npm run test:e2e
```

Математичні перевірки: рівновага мостів, відновлення невідомих величин, температурна регресія, одиниці, резонанс, індуктивність та допустимі покази потужності. Браузерні перевірки: усі 8 стендів, перетягування контакту, ручки клавіатурою, провід, прогрівання, полярність діода, осердя та конденсатор, навантаження, справжній сигнал на WebGPU-екрані, журнал, CSV і мобільний fallback.

Playwright налаштовано на встановлений Google Chrome (`channel: 'chrome'`) і запускає його в ізольованому тестовому профілі. Якщо Chrome не встановлено, встановити його або змінити channel відповідно до свого браузера.

## Файли

- `src/config.ts` — параметри, формули, пояснення та відповіді на контрольні питання.
- `src/physics.ts` — моделі, розрахунки й регресія.
- `src/workbench.ts` — малюнки восьми стендів та взаємодія з ними.
- `src/apparatus-renderer.ts` — прозорий WebGPU/WebGL та Canvas fallback.
- `src/main.ts` — сторінки, журнал і взаємодії.
- `src/storage.ts` — локальне збереження та CSV.
- `src/source.json` — питання, обладнання та посилання на рисунки з Markdown-описів.
- `public/docs/` — копія описів та 16 вирізаних рисунків.
- `.openai/hosting.json` — ідентичність і статична конфігурація Sites.

Демонстраційні моделі призначені для вивчення залежностей і не є результатами реального лабораторного досліду. ВАХ діода має задані ілюстративні параметри; пробій не моделюється. Температурна модель напівпровідника описує власну провідність, і оцінку ΔW слід трактувати в її межах.
